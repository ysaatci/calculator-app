# Prompts

General prompts used with Claude Code to build this project, in order.

## Planning

- Here is the assignment. Plan the project and set up a clean repository structure before writing code.
- Make the backend extendable for new operations using a strategy pattern.
- Draw a system design diagram of the frontend, API layer, endpoints and domain before we start.

## Building

- Build the project from the plan and commit in small, meaningful steps.
- Apply UX laws such as Hick's, Miller's and Fitts's to the UI, and keep it usable on mobile.
- Add Docker so the whole stack runs with one command.
- Create the GitHub repository and push.

## Improving

- Review the whole project and list what can be improved.
- Fix the bugs and the smaller items.
- Add exponentiation, square root and percentage, and make the diagram cleaner.
- Review UI/UX, architecture, testing and observability.
- How should we add observability to this app?
- Review performance and testing, and add Playwright.
- Review the design and fix the software design issues.
- Clean up the UI.
- Review again and fix the bug you found.
- Would an alerting tool fit our design?
- Check the codebase against SOLID and apply only the changes that make it cleaner and more extendable.
- Update the prompts and the diagram to match the final code.
- Make the documentation more concise.
